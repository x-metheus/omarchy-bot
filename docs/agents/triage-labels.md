# Triage labels

Use these GitHub labels when a skill names a triage role.

| Role | GitHub label | Apply when |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The reporter needs to supply more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified well enough for an agent to implement independently. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | A maintainer has declined the work. |
