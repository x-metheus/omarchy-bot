A desktop app with an Agent Daemon

The Tauri desktop app pairs with a standalone Rust daemon that runs Bots through Rig. Run the daemon on your computer or another machine.

Pick up where you left off

Give each Bot an ongoing job in chat. The daemon saves its Message History so you can return to the same Conversation.

Work with files and tools

Attach files to a Conversation. Tools can run in a configured workspace on the daemon host. To use tools on your desktop, choose a file or directory and approve each request in the app.

Frequently asked questions

Can work continue when I close the app? +

The Agent Daemon can keep working after the desktop disconnects. Closing the app ends access to tools on that desktop.

Which model providers can I use?+

After pairing, choose an OpenAI or Anthropic model and enter its API key in Settings. You can create Bots and read Conversations before configuring a provider. Replies require a configured model.

How do I connect to a remote daemon? +

Pair with the daemon's private HTTPS address and a one-time code. The desktop saves its device credential in the OS keychain.

What happens when I delete a Bot?+

The daemon permanently deletes the Bot and its Conversation. Shared preferences saved on the daemon remain available.

Is Omarchy Bot free?+

The source is available under the MIT license. Your model provider may charge for usage.
