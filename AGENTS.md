# AGENTS.md

Project rules live in `docs/agents/`. Read the matching file before doing that kind of work; each rule there is binding.

| Rule | When it applies | File |
| ---- | --------------- | ---- |
| Host safety | Always. Read before running anything on this machine. | `docs/agents/host-safety.md` |
| Domain docs | Before exploring code; multi-context layout routed by `CONTEXT-MAP.md`. | `docs/agents/domain.md` |
| Issue tracker | Issues and specs, tracked as local Markdown under `.scratch/<feature>/`. | `docs/agents/issue-tracker.md` |
| Triage labels | Labelling issues; the five canonical labels, no overrides. | `docs/agents/triage-labels.md` |
| Worktrees | Creating, merging, or cleaning up git worktrees. | `docs/agents/worktrees.md` |
